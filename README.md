# Sales Analysis Dashboard (Power BI)

## Overview

This project is an interactive Power BI Sales Analysis Dashboard designed to provide actionable insights into sales performance, profitability, customer behavior, and business growth trends.

The dashboard enables users to monitor key business metrics, identify top-performing categories and regions, analyze customer trends, and make data-driven decisions through interactive visualizations.

---

## Features

### Executive Overview

* Revenue KPIs
* Profit KPIs
* Order Analysis
* Performance Summary Cards

### Sales Analysis

* Sales trends over time
* Revenue growth analysis
* Category-wise sales performance
* Region-wise sales comparison

### Customer Insights

* Customer contribution analysis
* Customer segmentation
* Purchase behavior analysis

### Geographic Analysis

* Map-based sales visualization
* Regional performance comparison
* Location-wise revenue insights

### Profitability Analysis

* Profit trends
* Revenue vs Profit comparison
* High and low performing segments

### Advanced Analytics

* Waterfall Chart for contribution analysis
* Decomposition Tree for root-cause analysis
* Key Influencers visual for identifying factors affecting performance
* Scatter Plot for relationship analysis

### Interactive Features

* Dynamic filtering using slicers
* Drill-down capabilities
* Cross-filtering between visuals
* Interactive dashboard navigation
